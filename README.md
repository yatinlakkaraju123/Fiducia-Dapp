Voting Application
First ChairPerson creates a voting event
![image](https://github.com/user-attachments/assets/9544a7f0-e39b-44cf-97d3-a4eca0900e81)
The above image is a zoomed out image of how a chairperson creates a voting event
A smart contract is created for this voting event and a token number is generated which is mapped with the smart contract address and sent to all eligible voters via email.
![image](https://github.com/user-attachments/assets/8ec20b81-6936-47f5-a4c0-0d0f50739026)
![image](https://github.com/user-attachments/assets/e3858222-60af-4357-a52d-9213877ade85)
Voter Home page
![image](https://github.com/user-attachments/assets/bdd57181-eb74-460c-b230-b14a52c1bef7)
Voter Home Page of Voting Application
![image](https://github.com/user-attachments/assets/14f047ac-ae48-43b3-a7d2-f83dfa0cc565)
To register first the voter has to enter the token number to get the voting event
![image](https://github.com/user-attachments/assets/06499199-9e27-4fca-ab3d-1812b23596cf)
Then he has to enter the registration number which was given in the voter's list the csv file uploaded by the chairperson
![image](https://github.com/user-attachments/assets/4698a873-b8d9-407e-9ad6-e4a41e5b7d52)
After this authentication is done the register button will appear using which the voter has to register. The smart contract will register the Ethereum address from which the voter has registered and the registration number which the voter has entered for authentication.
![image](https://github.com/user-attachments/assets/155fff34-4a15-4402-98d9-9d5146541a64)
Now to vote the voter has to enter the token number
![image](https://github.com/user-attachments/assets/afc52efe-f979-4d15-85c4-f0a5c17aa12d)
After which the voting page will appear. By clicking load candidates, the candidates will appear and voter can vote for any one candidate after which he cannot vote again
![image](https://github.com/user-attachments/assets/049c2b72-156e-44ec-b000-51136831d426)
After voting the candidate can view the results.
![image](https://github.com/user-attachments/assets/1a1275ce-1dc0-4970-aec5-0a87d697c853)
The results is shown in the form of bar graph
FEEDBACK APPLICATION
![image](https://github.com/user-attachments/assets/9da4201c-720f-4658-8fbb-99a09c3ef88b)
Chairperson Feedback Home Page
![image](https://github.com/user-attachments/assets/1c162889-6ed5-4e4d-b466-3020e3deeea4)
Chairperson creating feedback form
Similar to voting process after entering necessary details a smart contract for the feedback event is created and a token number to map the smart contract address is generated and sent to all eligible users via email.
![image](https://github.com/user-attachments/assets/62b80d92-7d89-4193-9cc8-bd1b25566af9)
User's feedback home page
The user then register himself for giving feedback similar to the registration process in voting application
![image](https://github.com/user-attachments/assets/a12d6a26-6d56-4eb5-9ebd-f9471670efd1)
Then after registering the user can give his feedback by clicking on load feedback form button which loads the feedback given by the chairperson. The user's feedback will be stored anonymously.
![image](https://github.com/user-attachments/assets/58d78702-148d-4319-b1be-16149fd6caa3)
After all users give feedback the chairperson can view the feedbacks without knowing the user who has given the feedback
